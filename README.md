# PawMates

## About

PawMates is a web-based social networking platform focused on animal adoption.

The application allows users to create accounts, share posts, discover animals available for adoption, interact with other users, and submit adoption requests.

The goal of the project is to combine social networking features with an animal adoption platform.

## Features

* User registration and authentication
* User profiles
* Create and view posts
* Discover animals available for adoption
* View animal information
* Submit adoption requests
* Manage adoption requests
* Interact with other users

## Installation

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

Open the `backend` folder with IntelliJ IDEA and run the Spring Boot application.

Make sure MySQL is running and the database configuration is correctly configured.
